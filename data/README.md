# 本地视频

本目录的视频默认不进入 Git 历史。代码与学习文档可上传 GitHub；
个人视频、模型权重和实验输出保存在本地。

第一课请准备一段 15—25 秒的视频，命名为 `tabletop_01.mp4`：

1. 固定手机，横屏拍摄一个光照充足的桌面。
2. 桌面上放一个普通杯子或瓶子，尽量与背景颜色不同。
3. 前 5 秒保持无遮挡。
4. 把手或不透明纸板放在靠近目标的位置，挡住杯子/瓶子约 2 秒，再移开。让背景始终可见，避免贴近镜头挡住整个画面。
5. 再次遮挡目标，同时把它移动到另一处，然后移开手。
6. 最后让目标保持可见几秒。

优先使用 720p 或 1080p、约 30 FPS；手机导出支持时选择 H.264 MP4。
拍摄时避开人脸、屏幕、证件等与实验无关的内容。

已有 `tabletop_01.mp4` 是竖屏瓶子视频，可读取，包含两次几乎整幅画面的遮挡及瓶子位移。
保留这段作为画面中断样例。补拍 `tabletop_02.mp4` 已读取，后半段有纸板遮挡瓶子、背景保持可见及瓶子位移，可用于基线开发。竖屏也可运行，固定机位、目标清楚和背景持续可见更关键。

`synthetic_io.avi` 可以由 `scripts/make_sample_video.py` 生成。
它只用于验证读取和保存功能，不用于证明模型性能。

`tabletop_wrong_bottle_01.mp4` 为 2026-10-01 用户新提供的开发负例：原红白标签瓶子遮挡后换成红盖蓝标签的另一只瓶子。用户确认原瓶子未再入镜。633 帧、720×1280，约 21.16 秒；真实合格候选被拒绝，结果与限制见 `docs/wrong_bottle_m2_validation.md`。遮挡阶段挡住整个镜头，不能代表背景持续可见的目标遮挡负例；不充当 M3 保留测试。
