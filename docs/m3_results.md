正确返回依独立物理身份和本帧实际框与原图人工框 IoU>=0.5，不要求 A/B 产生自定义接受事件。C 两接受框经核对；10 帧延迟名义时间约 0.333278 秒、源时间 0.333333 秒；4 帧分别约 0.133311 / 0.133289 秒。锚点是保守可辨认时刻，不宣称精确最早重现。

一次替换的 130 帧是清楚 T2 区间的候选匹配范围，不是 130 张逐帧精确人工框，也不是 130 次独立实验。整次 C 133 候选 = 131 程序拒绝 + 2 质量暂缓；f390/f391 的暂缓及 f442 的程序拒绝局部几何未评价，不混入 130 分母。A/B 不绑定不等于外观拒绝通过。原目标无返回机会，不报虚假的零延迟或一次恢复失败。

## 方法贡献、失败与未评价

A 不改 ByteTrack，仅沿人工初始化选定的原生 ID 输出本帧检测框；B 复用 TargetState，本帧已关联轨迹框有检测映射，确认丢失后仅候选；C 新增冻结参考、多项外观/质量/竞争门控、有界纹理对齐和连续确认绑定。真值只用于评价。原生 ID 本身不证明物理身份。

- 两个正例初始化 ID1，返回瓶子的 ID3 不被 A/B 接续，导致各两次未返回。ByteTrack 已有短时失活保留与重新关联；第一片连续无检测 [172,203) 共 31 帧超过缓冲 30，第二片共 100 帧。本次没有原生短时返回成功样本，不能断言 C 胜过所有原生关联策略。
- C 第一片 f210—213、第二片 f280—282 整瓶清楚仍 UNKNOWN；固定 f210/f280 留在失败分子。恢复成功不等于全程无误报。
- 三组在人工确定 T1 缺席的 25/92/375 帧（每组共 492）均未输出当前位置；已审计框中没有错误，不代表未标注全片零错误。第一片 f169 三组、第二片 f168 三组、替换片 f195 A/B 的局部完整框不足，仍未评价。
- 清楚负例瓶盖/形状通过，标签颜色/纹理/排序多个门槛共同失败；没有隔离纹理或有界对齐的独立贡献。
- 拍摄者确认物理操作；框/可见性由 Codex 查看原图标注，未由第二位人类逐帧复核。保守锚点、不确定边界与局部几何不足保留。
- 第一片较短遮挡长于计划 0.3—0.5 秒，清楚后段约 4.4 秒少于 5 秒；第三片替换遮挡约 8 秒长于 3—4 秒计划，后段约 4.3 秒少于 5 秒。未按算法结果补拍或筛片；这是有拍摄偏差的小规模保留测试。
- 全片精确率/误报率未评价，速度未验证；真实双瓶歧义、同包装替换、困难例、泛化与纹理独立贡献未验证。2/2 不支持通用 100% 准确率，同包装不同实体可能误认。

## 精确实验复现

公开 Git 不含原视频、检测缓存、真值包、权重、环境或状态视频。运行自己的视频见 [主流程](run_demo.md)，不需要下面的私有数据包；**精确复现本表数字需要原本地包以及对应 Git 历史**。

必要本地包包括三份上述源视频、`outputs/m3_holdout_cache_v1/` 三缓存、`outputs/m3_holdout_annotations_v1/`、`outputs/m3_holdout_annotations_v2/`、`outputs/m3_holdout_input_confirmed_20261003/` 物理操作依据，及冻结清单所引用的开发缓存/标注/安装快照/模型等保全来源。仅拷三个 MP4 不足以运行严格来源核查；以协议和冻结清单的所有 `path` / SHA 引用为准。历史运行/评价核查需要 `.git` 中对应提交，不能改旧 SHA 绕过核查。

在包含该本地包的项目根目录，先查冻结，再复用原公共缓存运行；没有重新推理模型：
